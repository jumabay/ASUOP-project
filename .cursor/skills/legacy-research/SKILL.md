# Legacy Research
1. Read existing docs/analysis evidence and list exact artifacts to inspect.
2. Identify entry points, UI actions, SQL, Oracle packages and external file flows without modifying originals.
3. Mark each finding CONFIRMED, INFERRED or UNKNOWN with file/method/SQL citations.
4. Produce a scoped analysis report and unresolved questions.
5. Do not execute external sends, imports or DB writes; stop at agreed scope.
