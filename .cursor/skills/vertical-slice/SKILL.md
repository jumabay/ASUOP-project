# Vertical Slice
1. Verify approved task ID/acceptance criteria and read relevant design.
2. Identify minimal affected files; decline unrelated cleanup.
3. Write focused tests and implement one API + UI path with limited data.
4. Run authorized build/tests and compare with legacy behavior.
5. Report evidence and STOP. Do not initiate the next feature.
