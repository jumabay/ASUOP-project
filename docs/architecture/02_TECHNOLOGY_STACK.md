# 02. Технологический стек

Решение: [ADR-0001](decisions/ADR-0001-java-modular-monolith.md), [ADR-0003](decisions/ADR-0003-oracle-jdbc-19c-against-12-2.md), [ADR-0005](decisions/ADR-0005-react-antd-ag-grid.md).

Проверка совместимости сделана по открытым матрицам Oracle JDBC FAQ и Spring Modulith Appendix (ноябрь 2026). Версии библиотек в репозиторий не ставятся, пока нет отдельного согласия на код.

## Выбранная связка

| Слой | Выбор | Почему это требование системы, а не мода |
| --- | --- | --- |
| Язык | Java 21 LTS | Срок эксплуатации 10–15 лет. Spring Boot 3.5 собирается на 17 и 21. Java 25 не берётся базой, пока не пройден smoke-test JDBC к Oracle 12.2 |
| Приложение | Spring Boot 3.5.x | Один процесс, REST, безопасность, планировщик, JDBC |
| Границы модулей | Spring Modulith 1.4.x | Линия 1.4 собрана против Boot 3.5. Проверяет циклы и чужие типы без второго деплоя |
| HTTP | Spring MVC, OpenAPI | 20–30 пользователей. Браузер не открывает Oracle |
| Безопасность | Spring Security | Проверка права на сервере до вызова пакета. Старый `GetData` флаг операции не читает |
| Данные | Spring JDBC, `JdbcClient`, `CallableStatement` | Контракт старых клиентов — пакеты `DBTC`, не таблицы в коде UI |
| ORM | не применяется к ленте среза и архивам | `STATEREPORTRECORDS` около 1,2 млрд строк, PK нет. См. [ADR-0002](decisions/ADR-0002-jdbc-not-jpa-on-history.md) |
| Драйвер | `ojdbc10:19.33.0.0` + `orai18n:19.33.0.0` | JDBC 23.x к 12.2 = No. NLS нужен для `CL8MSWIN1251`. Smoke 2026-11-14 успешен ([21_JDBC_SMOKE_CHECK.md](21_JDBC_SMOKE_CHECK.md)). ADR-0003 |
| Миграции | Flyway только для отдельной схемы метаданных приложения | DDL ленты `DBTC` этим проектом не выполняется. См. [ADR-0006](decisions/ADR-0006-flyway-app-schema-only.md) |
| Фон | `ApplicationRunner` / `@Scheduled` в том же JVM | Наблюдатель файла и календарь часа. Очередь не вводится до измерения |
| UI | React, TypeScript, Vite, Ant Design, AG Grid Community | Боковое меню, вкладки, реестры порядка 18 тыс. строк. Картинки макетов не входят в этот набор |
| Тесты | JUnit 5. Testcontainers — только если копия Oracle доступна контейнером; иначе интеграционный прогон против выданной тестовой Oracle. Playwright — с первого экрана, не в R0 | R0 не открывает базу |
| Поставка | один каталог публикации, Git, откат предыдущим каталогом | Kubernetes не требуется для 20–30 пользователей |

Не входят на старте: Kafka, RabbitMQ, Redis, Kubernetes, микросервисы, JPA/Hibernate на исторических таблицах.

## Oracle, с которой стыкуемся

Подтверждено словарём на `tc-asuvp-03:1521/RAC.WORLD`, схема `DBTC`: **12.2.0.1.0**. Premier Support 12.2 закончился. Это факт совместимости, не разрешение менять промышленную базу.

| Драйвер | Database 12.2 по FAQ Oracle | JDK |
| --- | --- | --- |
| JDBC 23.x / 26ai `ojdbc17` | No | 17, 21, 25 |
| JDBC 21.x `ojdbc11` | Was | 11, 17, 21 |
| JDBC 19.x `ojdbc10` / `ojdbc8` | Was. На Maven Central линия 19c — `ojdbc8`/`ojdbc10` (нет `ojdbc11:19.x`). Страница загрузок 19c перечисляет 12.2 | `ojdbc10`: JDK 11/17; smoke на Java 21 с `ojdbc10:19.33.0.0` |
| JDBC 12.2 `ojdbc8` | Was | JDK 8. Со Spring Boot 3 не стыкуется: Boot 3 требует Java 17+ |

Рабочая связка до апгрейда базы: **Java 21 + `ojdbc10:19.33.0.0`**. Она не является официально сопровождаемой парой «свежий драйвер + 12.2». Поэтому первый код, который откроет соединение, делает только короткие диагностические `SELECT` по scoped-разрешению и фиксирует успех или отказ. `ojdbc11:23.x` не используется.

Если smoke-test на копии не открывает 12.2, хост приложения не подключается к базе. Обход через второй неподдерживаемый драйвер не проектируется. Дальше два разрешённых пути, оба отдельным решением DBA: обновление Oracle до 19c (LTS, Premier Support до декабря 2029 по странице Oracle) либо явный отказ от Java-чтения до этого обновления. Парсер файла R0 от этого не зависит: он Oracle не открывает.

## Почему не микросервисы и не брокер

НУВ, УВП, НУД и отчёты уже сидят на одном `ApplicationService` и одной схеме. Запись среза, проводка ремонта и проводка склада обязаны иметь одного писателя. Тела `ImportPkg`, `RepairsPkg.Register` и `WarehousePkg.Register*` не прочитаны. Второй процесс с правом DML становится вторым писателем. См. [ADR-0004](decisions/ADR-0004-no-message-broker.md).

Ориентир приёма полного файла — около 18 000 строк в час. Один проход массивом параметров укладывается в час, если измерение на копии это подтвердит. Брокер рассматривается только если этот проход не успевает за час или выбивает карточку из порога пула `Ui`.

## Сборка, которую увидит разработчик

Один Gradle-проект, когда код будет разрешён. Сейчас каталога приложения нет.

```text
railway-platform/
  platform-app/            Spring Boot + Modulith
  platform-oracle/         шлюз пакетов и три пула
  platform-disl-parser/    разбор KZ без JDBC
  modules/                 access, reference, fleet, dislocation,
                           movement, repairs, warehouse, reports,
                           operations, expedition, finance, integration-1c
  frontend/                Vite, React, TypeScript
```

`expedition`, `finance` и `integration-1c` остаются пустыми границами, пока нет отдельного задания. Бизнес-правила в них не выдумываются.
