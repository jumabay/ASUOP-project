# 20. Первый этап реализации

Состав R0 разрешён журналом [APPROVALS_TEMPLATE.md](APPROVALS_TEMPLATE.md) (2026-11-13). Исходники этим документом не создаются: их пишет следующий агент-этап и только библиотека `platform-disl-parser`.

Приложение-хост, React, FTP и Oracle в R0 не создаются. База не меняется. Старые программы не меняются.

## Цель

Библиотека `platform-disl-parser`: разбор строки KZ и локальный журнал часа. Проверяемый результат — сборка тестов на синтетической фикстуре по контракту строки из [01_ASUVP_IMPORT_PIPELINE.md](../analysis/01_ASUVP_IMPORT_PIPELINE.md).

Фикстура не объявляется образцом промышленного `disl_kz*.txt`. Тест не доказывает, что старый `ImportPkg` сохраняет неподвижный вагон. Он доказывает, что новый разборщик сам строку не выбрасывает и сам ключ не двоит.

## Зависимости

Нет. Учётка Oracle не нужна. Образец промышленного файла не нужен. Модули Spring не нужны.

## Задачи

- Разбор строки из 20 полей и строки из 21 поля. Контейнеры есть только у 21-го поля.
- Пустой файл не создаёт комплект в журнале часа.
- Две строки с одной станцией и одной операцией обе остаются в часе.
- Повтор того же имени и типа не создаёт второй комплект в локальном журнале.
- Пропущенный час виден в календаре канала.
- В дереве исходников нет JDBC, нет строки соединения, нет вызова `ImportPkg`.

## Критерии готовности

- Тесты JUnit 5 зелёные.
- Сборка не тянет Oracle и не открывает сеть.
- Дифф не содержит файлов старых программ и не содержит секретов.
- Документ пробелов не помечает G1 закрытым: R0 его не закрывает.

## Тесты

Набор из раздела «Проверки R0» в [16_TESTING_STRATEGY.md](16_TESTING_STRATEGY.md). Это не группа A и не группа B.

## Риски

- Контракт полей взят из вызова C#, не из тела пакета. Если пакет отбрасывает поле, парсер об этом не узнает. Поэтому парсер не пишет в базу.
- Нет промышленного образца. Фикстура может разойтись с живым файлом по кодировке и переводам строк. Первое сравнение с живым файлом — отдельное разрешение и не часть R0.
- Успех R0 легко принять за готовность импортёра. Включение писателя этим успехом запрещено.

## Проверка результата

Запуск тестов модуля. Просмотр дерева: нет зависимости `ojdbc` и нет `spring-boot-starter-jdbc` у этого модуля.

## Откат

Удаление каталога `platform-disl-parser` из будущего проекта либо отказ принимать изменение в основную ветку. База не затрагивается, откатывать в ней нечего.
