# 13. Безопасность

Источник прав — enum `DirectoriesLib.Items.Users.Operations` и таблицы `USERS` (29 входящих FK), `PERMISSIONS`. Полный список членов enum в одной декомпиляции не снимался. Неизвестный код в новый каталог не добавляется.

Старый `RemoteLib.DbManagerCall.GetData` флаг операции не читает: ему достаточно живой сессии. Этот обход не повторяется. Новый UI проверяет право на сервере до вызова пакета.

В НУД видны вызовы `Connect`, `SecureConnect` и `DomainConnect`. Это имена методов клиента, не описание развёрнутого Active Directory. Есть ли домен в инфраструктуре компании, в материалах не подтверждено.

## Вход

Пока не подтверждён каталог, вход платформы — локальная учётная запись приложения, сверенная с `USERS` на копии. Пароли в документы и в журнал не пишутся. Смена пароля и отключение сессии остаются у старого клиента, пока экран входа не пройдёт сверку с `USERS`.

Если заказчик подтвердит Active Directory или LDAP, Spring Security подключает этот каталог отдельным профилем. Локальный вход при этом остаётся запасным только для служебной учётки восстановления, не для ежедневной работы диспетчера. До подтверждения каталога профиль LDAP в конфигурации не включается и сервер каталога не опрашивается.

Сессия — cookie сервера приложений, `HttpOnly`, `Secure`, `SameSite`. Токен в `localStorage` не кладётся. Браузер строку соединения не получает.

## Аудит и секреты

Журнал пишет: кто, какой экран, какой ключ объекта, успех или код ошибки, имя файла и час. Текст запроса и значения фильтров не пишутся. Старый журнал, куда попадал полный SQL, не копируется.

Секреты вне репозитория и вне документов архитектуры: пароль Oracle, пароль LDAP, секрет 1С, ключи FTP. Каталог публикации их не содержит. Учётка Oracle приложения не совпадает с `asuvp_thread_*` и на чтении не имеет `INSERT` в `STATEREPORTRECORDS`.

API принимает только аутентифицированный запрос. Состояние изменяющие вызовы, когда они появятся, требуют права записи модуля и флага, который по умолчанию выключен. CORS ограничивается происхождением веб-клиента. Произвольный SQL с клиента отвергается.

Защита обмена с 1С описана в [12_FINANCE_AND_1C.md](12_FINANCE_AND_1C.md). Пока обмена нет, секрет 1С не заводится.
