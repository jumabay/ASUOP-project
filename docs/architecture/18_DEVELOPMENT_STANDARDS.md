# 18. Правила разработки

Платформу ведёт один разработчик. Основной код пишет агент только после явного согласия на конкретный этап. Следующий этап сам не начинается.

## Обязательные ограничения

1. Один Gradle-проект и один процесс. Новый репозиторий модулей и новый слой абстракций не заводятся без ADR.
2. Имена модулей — из [03_MODULAR_ARCHITECTURE.md](03_MODULAR_ARCHITECTURE.md): `access`, `reference`, `fleet`, `dislocation`, `movement`, `repairs`, `warehouse`, `reports`, `operations`, `expedition`, `finance`, `integration-1c`.
3. Бизнес-правило живёт в одном модуле. Повтор процедуры Oracle в двух модулях запрещён.
4. Модуль наружу отдаёт интерфейс и DTO. Чужой JDBC и чужие таблицы не импортируются.
5. Важное решение фиксируется ADR в [decisions/](decisions/) до кода, который это решение воплощает.
6. Этап заканчивается сборкой и тестами этого этапа. Незакрытый тест не маскируется пропущенным сценарием.
7. Код существующих EXE, DLL и config не меняется.
8. Промышленная Oracle не меняется. Запись в тестовую Oracle не выполняется без разрешения. Подключение к 1С не выполняется без согласования.
9. Новые компоненты не устанавливаются автоматически. Параллельные агенты не запускаются без согласия.
10. Неизвестное фиксируется в [19_RISKS_AND_OPEN_QUESTIONS.md](19_RISKS_AND_OPEN_QUESTIONS.md), а не закрывается правдоподобным кодом.

## Как писать код, когда он разрешён

- Вызов Oracle — только из `platform-oracle` и только по имени пакета из белого списка.
- Класс записи не является бином Spring, пока флаг модуля выключен.
- Исторические таблицы не размечаются сущностями JPA.
- Журнал не содержит SQL, пароль и значения фильтров.
- Тест R0 не поднимает контекст Spring и не открывает сокет.
- Комментарий объясняет ограничение старого контура, а не пересказывает имя метода.

## Документация рядом с кодом

Каждый этап дописывает в соответствующий файл `docs/architecture/` факт, который изменился: открытый пробел закрыт, тест пройден, флаг записи остаётся выключенным. Пустые главы и вымышленные бизнес-правила не добавляются.

Формы Visual Studio в этой платформе не создаются: клиент — React, сервер — Spring. Правило Designer относится к окнам WinForms, если такое окно появится отдельным заданием. В текущих волнах его нет.

## Сборка этапа

Критерий рабочего этапа: команда сборки зелёная, тесты этапа зелёные, дифф не содержит секретов и не содержит файлов старых программ. Откат этапа — не включать его каталог в ссылку публикации. База из-за этапа чтения не откатывается, потому что этап чтения в неё не пишет.
