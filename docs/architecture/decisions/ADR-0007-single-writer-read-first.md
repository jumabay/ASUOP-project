# ADR-0007. Сначала чтение, один писатель

## Статус

Принято.

## Контекст

На каждый агрегат сейчас есть владелец записи в старом контуре. Идемпотентность импорта, проводки ремонта, проводки склада и сообщений 2612/2731 телами пакетов не доказана. Успех чтения уже лежащего среза не равен замене импортёра.

## Решение

Флаги записи модулей выключены. Классы записи не регистрируются в контексте Spring. Новый процесс отказывается поднять писатель среза, если конфигурация указывает живой старый импортёр. Замена писателя KZ обсуждается только после теста B1 на двух копиях. Промышленный DML этим решением не открывается.

## Последствия

Первый код, который имеет право существовать без учётки Oracle, — локальный разбор файла (R0). Экраны чтения ждут учётку копии и тесты группы A. Волны 6 и 7 не начинаются из интереса к полноте интерфейса.

## Уточнение после Accept ADR-0009 (2026-11-20)

До cutover legacy остаётся единственным writer в `DBTC`. После cutover единственный writer бизнес-данных — новое приложение → `RAILDB`. Accept direction **не** включает writer и **не** включает cutover.
