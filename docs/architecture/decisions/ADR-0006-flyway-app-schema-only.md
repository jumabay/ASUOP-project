# ADR-0006. Flyway только для схемы метаданных приложения

## Статус

Принято.

## Контекст

Промышленная схема `DBTC` обслуживает живые EXE. Лента срезов без секций и без первичного ключа. Архитектура не разрешает DDL этой ленты. Журнал часа на старте пишется в файл. Отдельные таблицы приложения (аудит UI, каталог полей) в исследовании не требуются до появления экрана, который не может жить в файле.

## Решение

Flyway не накатывается на `DBTC`. Если понадобится схема метаданных приложения, она создаётся отдельно и только после явного разрешения. До этого разрешения миграций в репозитории нет. Откат версии приложения не откатывает данные вагонов, потому что приложение их не меняет.

## Последствия

Нельзя «заодно» добавить индекс или секцию скриптом приложения. Окно физической модели ленты остаётся решением DBA после теста B1, как записано в стратегии хранения.
