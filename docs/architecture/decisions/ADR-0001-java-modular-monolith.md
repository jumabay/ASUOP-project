# ADR-0001. Java-монолит вместо C# и микросервисов

## Статус

Принято.

## Контекст

Исследование этапов 1–10 описывает пять контуров одной схемы `DBTC`: НУВ, УВП, НУД, служба импорта и отчёты внутри клиентов. Черновик архитектуры предлагал C# / .NET 10 / Blazor. Задание на платформу фиксирует Java и срок эксплуатации 10–15 лет. Разработчик один. Одновременных пользователей 20–30. Тела `ImportPkg`, `RepairsPkg.Register` и `WarehousePkg.Register*` не прочитаны, поэтому второй процесс с правом записи опасен.

## Решение

Один процесс Spring Boot 3.5 на Java 21. Модули проверяет Spring Modulith 1.4. Клиент — React. Микросервисы, Kubernetes, Kafka, RabbitMQ и Redis на старте не вводятся. Черновик C# / Blazor сохранён в `docs/architecture/_archive_csharp/` и стеком не является.

## Последствия

Границы модулей и волны миграции из черновика сохраняются. Меняется только технология хоста и UI. Выделение процесса позже возможно только вместе с единственным правом записи агрегата. Java 25 не является базой, пока не пройден smoke-test JDBC к Oracle 12.2.
