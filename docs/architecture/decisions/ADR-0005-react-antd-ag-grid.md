# ADR-0005. React, Ant Design и AG Grid

## Статус

Принято.

## Контекст

Нужен один корпоративный клиент: боковое меню, вкладки, реестр около 18 тыс. вагонов, карточка, история, формы чтения, выгрузка. Разработчик один, макеты отдельно не заказывались. Blazor отклонён вместе со стеком C#. Набор компонентов должен давать таблицу большого реестра и каркас приложения, а не собирается из несвязанных виджетов.

## Решение

React и TypeScript собираются Vite. Каркас экранов — Ant Design. Реестры — AG Grid Community. Сервер проверяет права и отдаёт JSON. Строка Oracle и текст SQL в браузер не попадают. Экран появляется только вместе с тестом группы A. Пункты без теста остаются недоступными.

## Последствия

Правило файла Designer для WinForms на эти экраны не распространяется: окон WinForms в платформе нет. Внешний вид задаётся документацией карты экранов, не картинками. Смена библиотеки таблиц позже ограничена модулем реестра, не доменными модулями Java.
