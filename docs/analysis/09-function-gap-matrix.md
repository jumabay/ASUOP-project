# Этап 9. Сверка функций и пробелов

> Для проектирования устарела (журнал [APPROVALS_TEMPLATE.md](../architecture/APPROVALS_TEMPLATE.md), 2026-11-13). Опора — [08_CROSS_SYSTEM_MATRIX.md](08_CROSS_SYSTEM_MATRIX.md) и [08_GAPS_AND_UNCERTAINTIES.md](08_GAPS_AND_UNCERTAINTIES.md).

Статусы: **факт** — есть файл или декомпилированный метод; **гипотеза** — имя или маска без тела PL/SQL или образца файла; **пробел** — материала нет.

| Функция | Где | Доказательство | Статус |
|---|---|---|---|
| Приём полного текстового среза KZ | `ImportStateReportsFtp`, маска `disl_kz*.txt` | этап 1 | факт |
| Запись каждой строки файла в `ImportPkg.SaveStateReportLineKz` | тот же класс, `SaveLines` | этап 1 | факт |
| Хранение строки, если вагон не двигался | тело `SaveStateReportLineKz` | PL/SQL не читался | пробел |
| Отдельный файл изменений каждый час | маска `disl_operations*.txt` | это импортёр РФ тип 1, не доказанная дельта KZ | гипотеза |

Критичные пробелы до проектирования данных, не до карты процессов:

1. Текст `ImportPkg.SaveStateReportLineKz` и `UpdateStateReport`.
2. Образец полного файла и файла изменений.
3. Read-only словарь тестовой `dbtc`.

Дубли: НУВ и УВП — один `WagonApp` с разной сборкой. Планировщик только у НУВ. Склад — отдельный `WarehouseApp`. Импорт и API — один `ApplicationService` с двумя профилями.
